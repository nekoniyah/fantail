# Fantail — Discord Alternative

**Fantail** is a semi-decentralized, secure and privacy-first social network. Semi-decentralized means that a main
client is used to connect to multiple instances, which are self-hosted community servers.

# Place

A place is basically a “Discord Server” with the following contents:

- Tags (decoration-only) & Roles (permissions and level)
- Text Channels (Hybrid Messages)
    - Send Paragraphs
    - Send Media (Images, Gifs, Videos)
    - Send Emotes
- Category Channels
- Display Channels (Only used for displaying a label in a Place’s channel list)
- Voice Channels: Permanent channels that are isolated “voice calls”.
    - Clicking on a Voice Channel connects you to the corresponding voice call.
    - If nobody’s in a voice call, the audio stream ends and is destroyed.
    - If someone joins an empty voice call, a new audio stream is created.
